# SunshineQ

The artwork of Foundation Sunshine: the product icon (the sun), the tray and notification icons for playing, paused and locked, the installer images,
and the source images and scripts they are made from.

| Path | What |
| --- | --- |
| `icons/` | the product and tray icons as `.ico` |
| `images/` | the icons, notification images and welcome picture as `.png` |
| `resized/` | the icons in every size the product draws |
| `NSIS/` | the installer pictures |
| `素材/` | the source images, including the sun without clouds (`无云.svg`) and the chibi figure |
| `工程文件/` | the Paint.NET project files of the tray and notification icons |
| `scripts/` | the scripts that resize the images and build the `.ico` files, with `requirements.txt` (MIT, see below) |
